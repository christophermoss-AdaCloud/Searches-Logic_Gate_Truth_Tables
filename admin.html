Big O: Why Speed Matters

Computer scientists use Big O notation to describe how an algorithm's performance changes as the amount of data (n) increases.

Efficiency Comparison

Linear Search - $O(n)$ "Direct Growth"

If items double, time doubles. 100 items = 100 steps.

Binary Search - $O(\log n)$ "Efficient Growth"

If items double, time only adds ONE step. 1,000,000 items = ~20 steps.

The Golden Rule

"Binary Search is so fast that you can search the names of every person on Earth (8 billion people) in just 33 steps."

Pro Tip

Always check if the list is sorted before picking an algorithm.
